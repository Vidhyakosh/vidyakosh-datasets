# Content status

Per-board narrative of what is downloadable from the Vidyakosh app right now, and what is on the
roadmap. Each status file is hand-maintained and matches the table in [`README.md`](../README.md).

- [`cbse.md`](./cbse.md) — CBSE, Classes 1–12
- [`icse.md`](./icse.md) — ICSE (Class 10) + ISC (Class 11–12)
- [`state-boards.md`](./state-boards.md) — 16 state boards

## Status legend

| Symbol | Meaning |
|---|---|
| ✅ | chapter list + summaries + NCERT solved questions, packaged & downloadable |
| 🟡 | chapter list + partial content (some chapters in the subject have content, the rest show "awaiting contribution" in the app) |
| ⚪ | chapter list only (no summaries / questions yet) |
| ❌ | subject not yet in the curriculum source — needs a `subjects.json` + chapter list first |
| n/a | subject is not in the syllabus for that class |

The numbers in the cells are `done/total` chapter counts.
